# Retail Analytics & Demand Forecasting Platform

End-to-end analytics project: ingestion, dbt star schema, business analytics, demand forecasting, and dashboards.

**Status:** Phase 1 (foundation) complete. See `phases.md` for the roadmap, `PRD.md` for requirements, `architecture.md` for design, and `rules.md` for standards.

## Quick start
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
make test
```
